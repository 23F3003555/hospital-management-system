# Hospital Management System

A web-based Hospital Management System developed using Django and Python.

This project helps manage doctors, patients, and appointments in a simple and organized way.

## Features

- Patient Management
  - Add patient
  - View patients
  - Edit patient
  - Delete patient

- Doctor Management
  - Add doctor
  - View doctors
  - Edit doctor
  - Delete doctor

- Appointment Management
  - Add appointment
  - View appointments
  - Manage appointment details

- Simple and user-friendly interface
- Django Admin support
- Static CSS styling

## Technologies Used

- Python
- Django
- HTML
- CSS
- SQLite
- Git & GitHub
